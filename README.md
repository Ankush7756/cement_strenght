# Business Tracking Website

A lightweight business tracking dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- KPI summary cards for critical business metrics.
- Activity table with client-side filtering.
- Form to add and track new KPI entries instantly.
- One-click JSON snapshot export for reporting.

## Run locally
```bash
python3 -m http.server 8000
```
Then open <http://localhost:8000>.
